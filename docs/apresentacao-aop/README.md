# Apresentação Oral do Projeto (AOP) — PPg-Bioinfo/UFRN, Edital 08/2026

Fontes dos slides da apresentação de 23/11/2026. A versão para apresentar
está publicada como artefato no claude.ai; aqui fica a cópia versionada.

- `deck.json`: ordem dos slides e blocos de tempo
- `deck.css`: estilo comum
- `slides/*.html`: um arquivo por slide; as notas de fala ficam em `<aside>`
- `capturas/`: telas do painel (retrato do banco de 29/10/2026, dados reais)

As capturas e os números dos slides vêm do banco do VigiGen. Nada é simulado.
